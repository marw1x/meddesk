What doctors ask before downloading

Do I need internet to run it?

No. It runs completely offline. You only need internet once, to download the file.

Where is patient data stored?

On the clinic computer itself. Nothing is uploaded, and you can back it up to a USB stick with one click.

Windows says the file is unrecognised. Is it safe?

That message appears for any program without a paid code-signing certificate. It is not a virus warning. Choose "More info" then "Run anyway". Message me first if you want to check.

Can I connect more than one computer?

Yes, in Asnaan, Clinic Desk and Clinic Manager. One computer acts as the main one and the others join it over the clinic network, with no internet.

What happens when the trial ends?

Everything you entered stays exactly as it is. Message me for the permanent licence and you continue from the same point.

Do you help with setup and training?

Yes. Installation, training and after-sales support are part of the price, not an add-on.
